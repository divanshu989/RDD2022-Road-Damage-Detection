About the System

Basic information about the technology behind this project.

🤖

YOLO11

The system uses a trained YOLO11 object detection model to locate and classify road damage directly within an image.

🗂️

RDD2022 Dataset

The model was developed using road images and annotations from the RDD2022 road damage detection dataset.

🎯

Object Detection

Unlike simple image classification, the system identifies both the type and approximate location of damage using bounding boxes.

Supported Damage Classes

The trained model contains nine RDD2022 classes.

D00 D01 D10 D11 D20 D40 D43 D44 D50
